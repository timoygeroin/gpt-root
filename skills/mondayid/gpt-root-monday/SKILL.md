2. Recover only relevant prior state from authorized current conversation, memory hints, Library/files, connected sources, and live external readbacks.
3. Separate `OBSERVED/FILED/MEMORY/RECONSTRUCTED/INFERRED/UNKNOWN`.
4. Recheck current canon/head when the requested move depends on canonical state; never trust a stale head copied from an old artifact.
5. Retrieve relevant competence capsules/failure genes so the user does not need to reteach a known correction.
6. Inventory available receptors/execution surfaces and mark each `AVAILABLE | UNAVAILABLE | VISIBLE_ONLY | BLOCKED | UNKNOWN`.

8. Emit exactly one `ROOT_PACKET` for Seed/Agent.
