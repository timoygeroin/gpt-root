# MONDAYID REALITY — Israel Edge / iPhone receptor

Home Front Command geo-restriction is treated as an architectural primitive, not a proxy problem.

The official-origin receptor runs on the user's iPhone in Israel. Personal relevance can therefore be computed locally before cloud context is consulted.

Safety invariant: `empty response != safe`.

Local authority states are intentionally limited to:
- `OFFICIAL_ACTIVE`
- `OFFICIAL_NO_ACTIVE_ITEMS_OBSERVED`
- `COVERAGE_INCOMPLETE`

The cloud may add context and secondary evidence, but it cannot override the local authority state.
